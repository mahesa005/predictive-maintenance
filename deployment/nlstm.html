Architecture Reference

Nested LSTM
Cell-in-Cell Architecture

A hierarchical memory architecture where the cell state itself undergoes a secondary LSTM-style gating operation — enabling richer temporal abstraction than standard LSTMs.

Concatenation
z
z = [h_{t-1} ; x_t]
The joint input vector formed by vertically stacking the previous hidden state h_{t-1} and the current input x_t. Every gate in both the outer and inner layer reads from this single shared context vector. Its dimension is (hidden_size + input_size). This design lets all gates simultaneously observe both what the model currently knows (h) and what it's currently seeing (x).
Shared across all gates
Outer Forget Gate
f_t
f_t = σ(W_f · z + b_f)
A sigmoid gate producing values in (0, 1) for each cell dimension. It decides how much of the temporary cell state c_temp contributes to c_t during the outer LSTM update. A value near 0 erases that memory dimension in c_temp; near 1 retains it fully. In the nested formulation, f_t gates the carry from c_{t-1} only into the intermediate c_temp, not directly into the final c_t.
Outer layer · gates c_temp formation
Outer Input Gate
i_t
i_t = σ(W_i · z + b_i)
Controls how much of the candidate memory c̃_t is written into c_temp. Works together with f_t in the outer layer: f_t controls what old memory to preserve in c_temp, while i_t controls what new information to inject into c_temp. Together they govern the intermediate cell state that the inner layer will then refine.
Outer layer · controls c̃_t write into c_temp
Candidate Cell State
c̃_t
c̃_t = tanh(W_c · z + b_c)
The proposed new content to add to memory, bounded to (−1, 1) by tanh. This is the raw "what to write" signal generated by a linear transformation of z. It doesn't enter c_t directly — it must be filtered by i_t first, and the resulting product contributes only to c_temp, which is then further processed by the inner gates.
Outer layer · proposed new memory content
Outer Output Gate
o_t
o_t = σ(W_o · z + b_o)
The sole output gate in the Nested LSTM. After the inner gates have produced the final c_t, the output gate determines which dimensions of tanh(c_t) are exposed as the hidden state h_t. This is the only mechanism that writes from the cell state into the hidden state, making it the bottleneck for what information is passed to the next timestep's computation and to the output layer.
Outer layer · exposes c_t → h_t
Inner Forget Gate
f_in
f_inner = σ(W_fi · z + b_fi)
The key novelty. This gate operates directly on c_{t-1} in the final cell state equation. It learns an independent, slower forgetting policy: while f_t governs forgetting inside c_temp (short-horizon), f_inner governs how much of c_{t-1} bypasses c_temp entirely and flows into c_t (long-horizon). This creates a two-timescale memory: one fast path through c_temp and one slow bypass path.
Inner layer · long-horizon cell bypass
Inner Input Gate
i_in
i_inner = σ(W_ii · z + b_ii)
Controls how much of tanh(c_temp) enters the final cell state c_t. While c_temp already encodes a standard LSTM update, this gate acts as a second filter — deciding whether that intermediate computation is relevant enough to affect c_t. Together with f_inner, it gives the inner layer full LSTM-like control over what enters c_t, treating c_temp as the inner "candidate" and c_{t-1} as the inner "past state."
Inner layer · gates c_temp → c_t
Temporary Cell State
c_tmp
c_temp = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t
An intermediate computational state that doesn't exist in a standard LSTM. It represents "what a vanilla LSTM would have computed as c_t." In the Nested LSTM, this is not the final cell state — it's an input candidate to the inner layer. The inner forget/input gates then decide how much of c_temp vs. raw c_{t-1} contributes to the actual final c_t. This two-level cell hierarchy is the core innovation.
Intermediate · standard LSTM cell output
Final Cell State
c_t
c_t = f_inner ⊙ c_{t-1} + i_inner ⊙ tanh(c_temp)
The culmination of the nested computation. This is a second-order cell update: it mixes a filtered version of the previous cell (long-term bypass via f_inner) with a filtered version of the processed intermediate state (i_inner ⊙ tanh(c_temp)). The tanh is applied to c_temp here to squash it into a bounded range before it's weighted by i_inner, preventing unbounded accumulation and making the inner gate's sigmoid meaningful.
Final · two-level hierarchical memory
Hidden State
h_t
h_t = o_t ⊙ tanh(c_t)
The model's externally visible state at timestep t. It's computed identically to a standard LSTM: the outer output gate o_t selectively exposes dimensions of the tanh-compressed cell state. However, since c_t is now a richer, hierarchically-computed state, h_t implicitly encodes two levels of temporal abstraction. This is passed to the output layer and fed back as the h_{t-1} input at the next timestep.
Output · externally visible representation
Prediction
ŷ
ŷ = σ(W_y · h_T + b_y)
Applied only after the final timestep T (many-to-one classification). The output layer projects from hidden_size to output_size via a learned weight matrix W_y, then applies sigmoid for binary classification. During training, the BCE loss with class weighting (cw for the positive class) is computed against y_true here. The gradient dy = (ŷ − y_true) is the seed of all backpropagation.
Final · binary classification output
F1
Forward Pass
Initialization
Before the sequence begins, hidden state h₀ and cell state c₀ are initialized to zero tensors of shape (hidden_size, batch_size). The GPU allocates these on the CuPy device. The model processes the entire batch simultaneously — no per-sample loop — which is the key GPU optimization over naive implementations.
F2
Forward Pass · each timestep t = 0…T−1
Input Concatenation & Outer Gate Computation
At each timestep, the input slice x_t (input_size × batch_size) is transposed and vertically stacked with h_{t-1} to form z (hidden+input × batch_size). This single vector is the input to all six gates simultaneously. The four outer gates are then computed in parallel matrix multiplications: f_t, i_t, c̃_t, o_t. Three use sigmoid (producing [0,1] gating coefficients) and c̃_t uses tanh (producing bounded candidate content).
z = vstack(h_{t-1}, x_t)
f_t = σ(Wf @ z + bf)
i_t = σ(Wi @ z + bi)
c̃_t = tanh(Wc @ z + bc)
o_t = σ(Wo @ z + bo)
F3
Forward Pass · each timestep t
Inner Gate Computation
Using the same z vector, the two inner gates are computed. These are entirely separate learned transformations — they share the input z but have their own weight matrices Wf_i and Wi_i. This means the inner gates can develop a completely different "opinion" about what to forget and write compared to the outer gates. They typically learn to operate at a different temporal frequency — more slowly varying, since they govern the deeper memory layer.
f_inner = σ(Wf_i @ z + bf_i)
i_inner = σ(Wi_i @ z + bi_i)
F4
Forward Pass · each timestep t
Two-Stage Cell State Update
This is the defining computation of Nested LSTM — two sequential cell state computations instead of one. Stage 1 runs the standard LSTM cell update to produce c_temp (a provisional cell state). Stage 2 treats c_temp as a candidate and applies a second gating operation to produce c_t, directly mixing in c_{t-1} via f_inner and filtered c_temp via i_inner. The full cache (z, all gates, c_temp, c_t, h_t, c_prev, h_prev) is stored for BPTT.
c_temp = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t ← outer (standard LSTM)
c_t = f_inner ⊙ c_{t-1} + i_inner ⊙ tanh(c_temp) ← inner (nested)
h_t = o_t ⊙ tanh(c_t)
Every intermediate value is cached in a list of tuples, one per timestep, because BPTT will traverse this list in reverse.
F5
Forward Pass · after sequence
Output Layer & Loss Computation
After processing all T timesteps, only the final h_T is used for prediction (many-to-one). A linear projection followed by sigmoid produces ŷ ∈ (0,1). During training, binary cross-entropy loss is computed with class weighting — positive-class samples are upweighted by the factor cw to handle class imbalance. The gradient of loss w.r.t. output is simply dy = ŷ − y_true, scaled by cw for positive samples.
ŷ = σ(Wy @ h_T + by)
L = −[cw · y log(ŷ) + (1−y) log(1−ŷ)]
dy = (ŷ − y_true) · cw [for positive class]
B1
Backpropagation Through Time
Output Layer Gradient
Backprop seeds from the output layer. The gradients for Wy and by are computed from dy and h_final. Then the gradient flows back into h_final: dh_next = Wy.T @ dy. Additionally, a zero tensor dc_next is initialized — this will accumulate the "future cell gradient" as we traverse timesteps in reverse. Both dh_next and dc_next are passed backward through each timestep.
∂L/∂Wy = dy @ h_T.T / batch
∂L/∂by = sum(dy) / batch
dh_next = Wy.T @ dy
B2
BPTT · each timestep in reverse
Output Gate & Cell State Gradient
At each timestep (processing from T−1 down to 0): first, the gradient through the output gate. Since h_t = o_t ⊙ tanh(c_t), we get: do = dh ⊙ tanh(c_t) (how much output gate affects loss) and dc_from_h = dh ⊙ o_t ⊙ (1 − tanh²(c_t)) (how loss flows from h back into c). The total cell gradient is dc = dc_from_h + dc_next, where dc_next carries gradient from future timesteps through the cell carry.
do = dh ⊙ tanh(c_t)
dc = dh ⊙ o_t ⊙ (1 − tanh²(c_t)) + dc_next
da_o = do ⊙ o_t ⊙ (1 − o_t) ← sigmoid derivative
B3
BPTT · each timestep in reverse
Inner Gate Gradients (Novel BPTT step)
This is the most complex gradient step, unique to Nested LSTM. The cell state equation c_t = f_inner ⊙ c_prev + i_inner ⊙ tanh(c_temp) creates gradients for both inner gates and a gradient into c_temp. The inner gates receive their own gradient signals through the standard sigmoid derivative. The key insight: gradient flows through tanh(c_temp) to reach dc_temp, which then propagates further to the outer gates.
di_inner = dc ⊙ tanh(c_temp)
df_inner = dc ⊙ c_prev
dc_temp = dc ⊙ i_inner ⊙ (1 − tanh²(c_temp)) ← through tanh
B4
BPTT · each timestep in reverse
Outer Gate Gradients (via c_temp)
With dc_temp known, the outer gates receive their gradients. From c_temp = f_t ⊙ c_prev + i_t ⊙ c̃_t: the outer forget gate gradient comes from dc_temp ⊙ c_prev, the outer input gate from dc_temp ⊙ c̃_t, and the candidate gradient from dc_temp ⊙ i_t (then through tanh derivative). Each activation gradient is then projected back through the weight matrix to compute parameter gradients (W and b grads are accumulated across the batch).
dc̃ = dc_temp ⊙ i_t → da_c = dc̃ ⊙ (1 − c̃_t²)
di = dc_temp ⊙ c̃_t → da_i = di ⊙ i_t ⊙ (1 − i_t)
df = dc_temp ⊙ c_prev → da_f = df ⊙ f_t ⊙ (1 − f_t)
B5
BPTT · each timestep in reverse
Two-Path Cell Carry & Hidden State Gradient
The critical insight for BPTT: c_prev appears in two places — once in c_temp (outer forget path) and once directly in c_t (inner forget path). Therefore, dc_next (the carry-back cell gradient) must sum both contributions. Similarly, dz is computed by multiplying all gate weight matrices transposed against their respective activation gradients. The hidden state carry dh_next is extracted as the first hidden_size rows of dz.
dz = Wf.T@da_f + Wi.T@da_i + Wc.T@da_c + Wo.T@da_o
+ Wf_i.T@da_f_inner + Wi_i.T@da_i_inner
dh_next = dz[:hidden_size, :] ← carries to prev h
dc_next = dc_temp ⊙ f_t + dc ⊙ f_inner ← two paths!
After processing all timesteps, gradients are clipped to [−5, 5] to prevent exploding gradients.
B6
Optimization
Adam Update with L2 Regularization
All parameters (10 weight matrices + 10 bias vectors for the Nested LSTM) are updated via Adam. For weight matrices, L2 regularization adds λ · W to the gradient before the Adam moments are computed. Adam maintains separate first (m) and second (v) moment estimates for every parameter, bias-corrected at each step t. This adaptive learning rate is critical for the nested architecture because the inner and outer gates have very different gradient magnitudes and need independent step sizes.
g_eff = g + λ·W [for W params]
m_k = β1·m_k + (1−β1)·g_eff
v_k = β2·v_k + (1−β2)·g_eff²
θ_k -= lr · (m_k/(1−β1^t)) / (√(v_k/(1−β2^t)) + ε)
I1
Inference
Stateless Forward Pass (No Cache)
At inference time, the model runs the identical forward computation — all six gates, both cell state stages, hidden state update — but does not store the cache because there is no backpropagation. Memory footprint drops from O(T × batch × hidden) during training to O(1) since only h and c from the current timestep need to be maintained. The final sigmoid output ŷ is thresholded (typically at 0.5) to produce binary predictions.
I2
Inference
Evaluation Metrics
The inherited evaluate() method converts GPU arrays back to NumPy (cp.asnumpy()) for metric computation. Predictions are thresholded at 0.5 to yield binary outputs. Standard classification metrics are computed: accuracy, precision, recall, F1, AUC-ROC. Given the class-weighted loss during training, the threshold may need tuning at inference time for optimal precision-recall tradeoff, especially on imbalanced datasets.
